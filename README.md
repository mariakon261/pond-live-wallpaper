# How to run

## 1. Clone the repository
`https://github.com/mariakon261/pond-live-wallpaper.git`

## 2. Linux - Hidamari
Hidamari ([Hidamari](https://github.com/jeffshee/hidamari))  is required to set a live linux desktop background.

1. Open ***Hidamari***.
2. Navigate to the wallpaper selection screen and choose Web Page
3. Broswer to the project's index.html file or enter the project's URL.
4. Apply the wallpaper. 

## 3. Windows - Lively Wallpaper
Lively ([Lively](https://github.com/lively-community/lively)) is required to set a live Windows desktop background.

Follow the same instructions. The animated pond should appear as your desktop background!
