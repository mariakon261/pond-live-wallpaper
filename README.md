# How to run

## 1. Clone the repository
`https://github.com/mariakon261/pond-live-wallpaper.git`

## 2. Load the wallpaper in Hidamari  ([Hidamari](https://github.com/jeffshee/hidamari) )
Hidamari is required in order to use the wallpaper as a live Linux desktop background

## 3. Load the wallpaper in Hidamari

1. Open ***Hidamari***.
2. Navigate to the wallpaper selection screen and choose the option ***"Web Page"***.
3. Broswer the project's index.html file and apply the wallpaper.

The animated pond should appear on your desktop background.
